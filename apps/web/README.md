# Scap Web

Landing page for Scap.

This should be built only after the native macOS MVP works.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- App Router
- Vercel target

## Role

The landing page sells the real app.

It should not promise features that do not exist.

## Product Message

Scap keeps screenshots and screen recordings in one clean local pocket on your Mac.

It can set a Scap folder as the macOS screenshot destination, then helps you browse, search and clean up those files.

## Hero

Headline:

Stop losing screenshots.

Subheadline:

A tiny Mac app that sends new screenshots into one local pocket, then helps you find or clean them up later.

CTA:

Get lifetime access

Microcopy:

No subscription. No account. Your screenshots stay on your Mac.

## Do Not

- do not claim Scap directly captures areas/windows/screens in V0.1
- do not mention Screen Recording permission as part of normal use
- do not add auth
- do not add dashboard
- do not add database
- do not add CMS
- do not add backend unless explicitly needed later
