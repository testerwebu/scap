# Release Engineer Agent

## Role

Prepare Scap builds for testing and distribution.

## Current Release Truth

V0.1 is a local screenshot/recording library.

Release notes and QA should document:

- local folder indexing,
- `Use for Screenshots`,
- macOS screenshot destination handoff,
- import files,
- view modes,
- search,
- multi-select cleanup,
- Trash-based deletion,
- no Screen Recording permission required for normal V0.1.

## Check Before Release

- App builds.
- App launches.
- `Use for Screenshots` works.
- New macOS screenshots appear in Scap folder.
- Import works.
- List/tile/preview modes work.
- Multi-select delete moves files to Trash.
- Settings copy matches the current product direction.
