# Phase 01 - Menu Bar and Library Shell

## Goal

Create the basic native macOS shell for Scap as a screenshot/recording library.

## Read First

- docs/01-product.md
- docs/02-design.md
- docs/03-architecture.md
- docs/roadmap/00-roadmap.md

## Scope

- Menu bar extra.
- Main library window.
- Settings window shell.
- Empty library state.
- Search field placeholder.
- Initial toolbar actions:
  - Use for Screenshots
  - Choose Folder
  - Import Files
  - Refresh
  - Settings

## Out of Scope

- Direct screen capture.
- Screen Recording permission.
- OCR.
- Database persistence.
- Landing page.

## Acceptance

- App builds and launches.
- User can open library window.
- UI clearly presents Scap as a local screenshot/recording library.
- Empty state points to folder/import flow, not capture modes.
