# Phase 10 - Polish

## Goal

Make the file-library workflow feel clear, fast and native.

## Scope

- Refine folder setup flow.
- Refine empty states.
- Refine view modes.
- Refine selection and batch delete.
- Improve thumbnails and list density.
- Improve menu bar popover.
- Improve error states for missing folders, unsupported files and delete failures.
- Verify light/dark appearance.

## Out of Scope

- Direct capture.
- OCR unless Phase 07 is active.
- Annotation/redaction unless Phase 12 is active.
- Landing page unless Phase 13 is active.

## Acceptance

- User can onboard without reading docs.
- User can clean up many screenshots quickly.
- User can find and reveal files predictably.
- App builds and launches cleanly.
