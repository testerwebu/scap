# Phase 00 - Project Setup

## Goal

Create the real native macOS project and repository structure.

## Scope

- Create `apps/mac/Scap.xcodeproj`.
- Create the Swift/SwiftUI app skeleton.
- Add app folders for App, UI, Services and Storage.
- Add docs and agent files.
- Verify the app builds.

## Direction Note

The current product is a local screenshot/recording library.

Do not scaffold the app around direct screen capture as the primary workflow.

## Out of Scope

- Folder watching.
- Import.
- Search.
- Hotkeys.
- Landing page.
- Direct capture.

## Acceptance

- Real Xcode project exists.
- App builds.
- App launches.
- No fake placeholder `.xcodeproj` is created.
