# Phase 13 - Landing Page

Post-V0.1 only.

## Goal

Create a landing page for the real native app after the app is usable.

## Product Message

Scap keeps screenshots and screen recordings in one local pocket on your Mac.

It can set a Scap folder as the macOS screenshot destination, then helps you browse, search and clean up those files.

## Sections

- Product hero
- Local screenshot library
- Use normal macOS shortcuts
- Tiles/list/preview browsing
- Fast cleanup with multi-select
- Local-first privacy
- Pricing
- FAQ

## Avoid

- Claims that Scap directly captures areas/windows/screens in V0.1.
- Screen Recording permission messaging.
- Cloud/team positioning.

## Acceptance

- Landing page accurately reflects the shipping app.
- No feature claims contradict the current V0.1 direction.
