# Phase 06 - Organization

## Goal

Turn local screenshots and recordings into findable saved information.

## Read First

- docs/01-product.md
- docs/04-data-model.md
- docs/02-design.md

## Scope

- Add editable title.
- Add note.
- Add category.
- Add project.
- Add tags.
- Add pinned/favorite state.
- Show metadata in item detail or side panel.
- Keep original files intact.

## Out of Scope

- Direct capture.
- OCR.
- Annotation/redaction.
- Cloud sync.

## Acceptance

- User can add context to an imported/watched file.
- Metadata persists locally.
- Search can later use this metadata.
