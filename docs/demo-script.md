# Demo Script

Use this when showing Scap to someone from a private GitHub repository or local screen share.

## Setup

- Open `apps/mac/Scap.xcodeproj`.
- Run the `Scap` scheme.
- Prepare a local folder with a few screenshots and one short screen recording.

## Five-Minute Demo

1. Show the app launching as a native macOS utility.
2. Choose the prepared screenshots folder or click `Use for Screenshots`.
3. Show new/imported files appearing in the library.
4. Switch between preview list, compact list and tiles.
5. Search for text from filenames, notes or OCR.
6. Add a project, tag and note to one screenshot.
7. Pin the screenshot and filter/search again.
8. Open and reveal a file in Finder.
9. Create an annotated copy or board from selected screenshots.
10. Move a disposable test file to Trash to show cleanup behavior.

## Suggested Talking Points

- Scap is local-first and private by default.
- It works with normal macOS screenshot shortcuts.
- It is currently a prototype for review, not a packaged public app.
- The biggest next engineering step is packaging plus automated tests.
