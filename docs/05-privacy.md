# Privacy

## Privacy Promise

Your screenshots stay on your Mac.

## Current Privacy Model

Scap works with local files and local metadata:

- screenshots,
- screen recordings,
- filenames,
- paths,
- titles,
- notes,
- projects,
- categories,
- tags,
- OCR text,
- annotation and board metadata.

No account is required. No backend is required. No cloud sync is part of the current prototype.

## OCR

OCR must run locally through Apple Vision.

No screenshot content, OCR text, notes, tags or paths should be sent to analytics or remote services in the current prototype.

## Permissions

The active workflow should not require Screen Recording permission.

Scap should avoid direct capture and instead:

- create or use a local Scap folder,
- ask the user to choose folders/files through native panels,
- set the macOS screenshot destination when the user chooses that option.

## Sensitive Data

Treat screenshots and recordings as sensitive by default.

They may contain:

- private conversations,
- client work,
- financial details,
- admin panels,
- documents,
- code,
- credentials visible by accident.

## Delete Behavior

Deleting from Scap should move files to the macOS Trash.

Batch delete must be explicit and confirmed.

## Copy

Use plain privacy copy:

- "Your screenshots stay on your Mac."
- "No account required."
- "No cloud sync."
- "OCR runs locally."
- "Scap watches a local folder."

Do not use Screen Recording permission copy in the normal workflow.
