# Scap video walkthrough

The product walkthrough uses actual native macOS UI captures with fictional sample data. Cursor movement, click highlights, zooms and transitions are added in editing; the timing is paced for readability. This is an edited demonstration, not an uninterrupted screen recording.

## Playback format

- Resolution: 1920 × 1080 (16:9).
- Frame rate: 60 fps.
- Format: MP4, H.264, yuv420p.
- Duration: 38 seconds.
- Audio: none; on-screen captions explain the actions.
- Streaming: MP4 metadata is placed at the start of the file (`faststart`).

The video is hosted as a GitHub attachment and embedded in the repository README. Static screenshots remain available in [the visual walkthrough](demo.md).

The footage shows an early prototype. It does not change the release status or the application code.
