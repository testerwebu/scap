# Codex Phase Prompt Template

Use this template when starting a phase.

## Required Reads

- AGENTS.md
- docs/00-index.md
- docs/01-product.md
- docs/02-design.md
- docs/roadmap/00-roadmap.md
- current phase file

## Phase Instruction

Work only on the current phase.

Do not build the landing page unless this is Phase 13.

Do not add backend, accounts, cloud sync or remote OCR.

Do not reintroduce direct screen capture unless the user explicitly changes scope.

Do not require Screen Recording permission for the normal V0.1 workflow.

Screenshots, recordings and metadata stay local.

## End of Phase

Report:

- what changed,
- files touched,
- build/test command,
- risks,
- next phase.
