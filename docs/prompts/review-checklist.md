# Review Checklist

Use this after each phase.

## Product Scope

- Did the work follow the current file-library direction?
- Did it avoid reintroducing direct capture?
- Did it avoid Screen Recording permission in the normal flow?
- Did it avoid landing page work before Phase 13?
- Did it stay local-first?

## UX

- Can the user understand how to get screenshots into Scap?
- Does `Use for Screenshots` explain the macOS folder handoff?
- Are imported/watched files easy to scan?
- Do tiles, list and list with preview behave predictably?
- Is batch delete reachable while scrolling?

## Privacy

- Are screenshots and recordings local?
- Are files moved to Trash instead of permanently deleted?
- Is batch delete explicit?
- Is there no remote OCR, analytics or upload?

## Engineering

- Does the app build?
- Does the app launch?
- Are file operations error-handled?
- Are unsupported files ignored gracefully?
- Are unrelated phases untouched?
